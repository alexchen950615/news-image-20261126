One image summing up the world news of Thursday 26 November 2026: a front-page style illustration headed by the date, with six panels — the US proposing new tariffs on 14 nations, Ukraine striking a Russian air base, Kim Jong Un calling for wider deployment of tactical nuclear weapons, the Cairo fuel-tanker fire that killed at least 30 people, Israeli judges casting doubt on Netanyahu's bribery charge, and the Macy's Thanksgiving Day Parade postponed by a storm.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` copies `entry.png` (1024×1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR/entry.png`, using only the Python standard library.
